# Windows IT Help Desk & User Account Management

## Project Overview
Simulated a Windows 11 Pro IT help desk environment to practice local user account management, permissions testing, and technical support documentation.

## Tools Used
- Windows 11 Pro
- Windows Settings
- Command Prompt
- User Account Control (UAC)
- Notepad

## Project Activities
1. Identified the Windows 11 Pro operating system.
2. Created a local test account named IT-TestUser.
3. Verified the account was configured as a Standard User.
4. Attempted to run Command Prompt as administrator and confirmed that Windows requested administrator credentials.
5. Opened Command Prompt normally to verify standard user access.
6. Documented the results in a simulated IT help desk support ticket.

## Results
Confirmed that Windows restricted elevated operations while allowing standard Command Prompt access. No permission changes were necessary.
